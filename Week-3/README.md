# Java Programming Internship — Week 3

## Topics
- Exception handling: try/catch/finally
- Multiple catch blocks
- Custom checked exceptions
- File I/O with readers and writers
- Collections and `ArrayList`
- Maps and word-frequency processing
- Mini project with persistent employee records

## Practice Solutions
1. `DivideByZero.java` — handles `ArithmeticException`.
2. `TextFileReadWrite.java` — writes, reads, and copies a text file.
3. `MultipleCatchDemo.java` — demonstrates multiple exception types.
4. `InvalidAgeException.java` + `CustomAgeValidation.java` — custom exception validation.
5. `WordCountFile.java` — counts words from a text file.
6. `StudentMarksRecord.java` — stores marks in an `ArrayList` and finds highest, lowest, and average.

## Assignment
- `FileIOAssignment.java` reads `input.txt`, calculates case-insensitive word frequencies, and writes them to `word_frequency.txt`.

## Mini Project
- `EmployeeManagementSystem.java` provides employee creation, searching, deletion support, validation, and file persistence using `employees.txt`.

## Compile

```bash
javac *.java
```

## Run examples

```bash
java DivideByZero
java TextFileReadWrite
java MultipleCatchDemo
java CustomAgeValidation
java WordCountFile
java StudentMarksRecord
java FileIOAssignment
java EmployeeManagementSystem
```

All Week 3 Java source files compile successfully with the standard Java compiler.

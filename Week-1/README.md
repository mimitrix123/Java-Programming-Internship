# Java Programming Internship — Week 1

## Java Basics Practice Set

Solutions to all five Week 1 practice questions from the provided internship material.

### Questions solved
1. Check whether a number is even or odd — `EvenOdd.java`
2. Find the sum of all elements in an array — `ArraySum.java`
3. Reverse a string — `ReverseString.java`
4. Swap two numbers without using a third variable — `SwapWithoutThirdVariable.java`
5. Print a multiplication table using loops — `MultiplicationTable.java`

## Compile and run

```bash
javac *.java
java EvenOdd
java ArraySum
java ReverseString
java SwapWithoutThirdVariable
java MultiplicationTable
```

## Concepts covered

- `Scanner` for user input
- `if/else`
- Arrays and loops
- `StringBuilder`
- Bitwise XOR operations
- `for` loops
- Basic input validation
